# davproj — Distributed Asset Management & RMM System

Комплексная система удаленного мониторинга и управления (RMM) парком рабочих станций на базе Windows. Разработана для работы в закрытых сетевых периметрах.

## 🛠 Архитектура решения

Проект построен на микросервисной архитектуре с разделением ответственности:

*   **davproj (Backend):** Серверная часть на ASP.NET Core. Отвечает за сбор данных, управление агентами и API для взаимодействия.
*   **ClientAPI (Agent):** Windows-служба (System Service), выполняющая сбор данных о HW/SW и исполнение команд сервера.
*   **VncTrayApp:** Пользовательское приложение (User Session) для взаимодействия с сотрудником (уведомления, подтверждение сессий), решающее проблему Session 0 Isolation.
*   **HardwareShared:** Общая библиотека моделей данных для типизации обмена между агентом и сервером.
*   **VncUriHandler:** Модуль для обработки кастомных URI (vnc://) для мгновенного запуска сессий из браузера.

## 🚀 DevOps и Автоматизация

*   **CI/CD:** Настроены пайплайны в **GitHub Actions** (.github/workflows) для автоматической сборки и валидации проекта.
*   **Deployment:** Автоматизированная сборка инсталляторов (MSI/EXE) через **WiX Toolset**, включая упаковку системных зависимостей (.NET Framework, VNC-компоненты).

## 💎 Ключевые технические решения

*   **IPC (Inter-Process Communication):** Реализовано взаимодействие между фоновой службой и пользовательским приложением через **Named Pipes**.
*   **SSO Auth:** Интеграция с Windows-сессией для бесшовной авторизации.
*   **Hardware Audit:** Модуль глубокого аудита железа и ПО с сохранением истории изменений.
